Guia: Com Publicar Aquest Dashboard de franc

Tot el codi d'aquesta aplicació està contingut en un **únic fitxer HTML**. Pots publicar-lo en pocs segons a qualsevol plataforma d'allotjament web gratuïta sense necessitat de servidors ni bases de dades.

Opció 1: GitHub Pages (Recomanada)

  1. Guarda aquest fitxer al teu ordinador amb el nom index.html.
  2. Crea un compte gratuït a GitHub.com i crea un repositori nou anomenat per exemple hematopoiesi.
  3. Puja el fitxer index.html al repositori.
  4. Vàs a Settings > Pages, tria la branca main i desa. En 1 minut tindràs la teua URL pública gratuïta!

Opció 2: Netlify Drop (Més ràpid - Sense programar)

  1. Visita app.netlify.com/drop.
  2. Arrossega la carpeta que conté el teu fitxer index.html.
  3. L'aplicació es publicarà a l'instant amb una URL web pública activa per sempre!
